## 🔧 开发规范

### 1. 代码注释
所有代码必须包含详细的中文注释，包括：
- 文件头说明（功能描述）
- 类说明
- 方法说明（参数、返回值）
- 关键逻辑说明

### 2. 命名规范
- 文件名：小写 + 下划线（如：`user_model.dart`）
- 类名：大驼峰（如：`UserModel`）
- 方法/变量：小驼峰（如：`getUserInfo`）
- 常量：大驼峰或全大写（如：`ApiConstants`、`BASE_URL`）

### 3. 分层架构
- **UI 层（Presentation）**：只负责显示和用户交互
- **业务层（Domain）**：处理业务逻辑
- **数据层（Data）**：处理数据来源（API、本地存储）

### 4. 状态管理
使用 Bloc 模式进行状态管理：
- Event：用户操作或外部触发的事件
- State：页面的状态（加载中、成功、失败等）
- Bloc：处理 Event，更新 State

## 💡 常见问题

### Q1: 如何添加新的 API 接口？
1. 在 `lib/data/datasources/remote/` 创建新的 API 服务文件
2. 使用 Retrofit 注解定义接口方法
3. 在 Repository 层调用 API 服务
4. 在 Bloc 中使用 Repository

### Q2: 如何添加新的页面？
1. 在 `lib/presentation/pages/` 创建页面文件
2. 在 `lib/core/routes/app_routes.dart` 添加路由名称
3. 在 `main.dart` 的 routes 表中注册路由
4. 使用 `Navigator.pushNamed(context, AppRoutes.xxx)` 跳转

### Q3: 如何使用 Bloc？
```dart
// 1. 创建 Event
abstract class ProductEvent extends Equatable {}
class LoadProducts extends ProductEvent {}

// 2. 创建 State
abstract class ProductState extends Equatable {}
class ProductsLoading extends ProductState {}
class ProductsLoaded extends ProductState {
  final List<Product> products;
}

// 3. 创建 Bloc
class ProductBloc extends Bloc<ProductEvent, ProductState> {
  @override
  Stream<ProductState> mapEventToState(ProductEvent event) async* {
    if (event is LoadProducts) {
      yield ProductsLoading();
      // 加载数据...
      yield ProductsLoaded(products);
    }
  }
}

// 4. 在页面中使用
BlocProvider(
  create: (_) => ProductBloc(),
  child: BlocBuilder<ProductBloc, ProductState>(
    builder: (context, state) {
      if (state is ProductsLoading) return LoadingWidget();
      if (state is ProductsLoaded) return ProductList(state.products);
      return Container();
    },
  ),
)
```
